# YaadSaathi (यादसाथी)

Frontend demo prototype for Smart India Hackathon: an elderly-friendly cognitive assistance UI for dementia care in the North Eastern Region of India.

This is a presentation prototype. It uses mock data and localStorage only. It is not a medical product.

## Run

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal (usually `http://localhost:5173`).

## Demo flow

1. Landing — enter any 4–6 digit PIN, or Create Account
2. Role selection — Patient, Caregiver, or Doctor
3. Patient — Memory Match game, Daily Routine, Voice Assistance
4. Caregiver — mock activity, reminders, share report
5. Doctor — session history, latency chart, difficulty cap

Core screens work from saved local data and show an offline status banner.
